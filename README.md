## GitHub Pages
This is a static HTML/CSS/JS site and can be published directly with GitHub Pages.

Recommended repository name:

`YOUR-GITHUB-USERNAME.github.io`

Then go to **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**.

GitHub Pages publishes the static files directly from the repository.
